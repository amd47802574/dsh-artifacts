# dsh-artifacts · 产物管家

一个 DeepSeek Harness (DSH) 插件：在左侧栏新增「产物管家」入口，集中浏览和管理 DSH 生成的产物文件。

![preview](docs/preview.svg)

## 功能

- **左侧栏入口**：彩色渐变图标，点击进入中央面板
- **产物目录随你定**：面板 ⚙ 设置里可用系统目录选择器选文件夹（或手动输入路径），保存后立即生效；别人下载安装后默认使用 `~/.dsh/artifacts`（首次自动创建），不再是作者的个人路径
- **卡片 / 列表两种视图**：一键切换，选择本地记忆；卡片按文件类型着色，图片显示真实缩略图
- **全局搜索**：顶栏输入产物名（支持中文），跨全部子目录即时搜索；结果带所在文件夹，可一键跳转，同样支持预览与管理
- **隐藏代码 / 脚本**：一键隐藏执行过程产生的 .py / .js / .sh 等代码脚本文件、.pyc 等编译缓存和 `__pycache__` / `node_modules` 等运行器目录，只看真正的产物；开关状态本地记忆，目录与搜索结果均生效
- **回收站**：删除默认进回收站（产物根下 `.dsh-artifacts-trash`，普通浏览与搜索不可见），可随时恢复到原位置、彻底删除单个或清空；重名恢复自动加序号后缀，绝不覆盖现有文件
- **目录浏览**：面包屑 + 上一级，跨层级自由跳转
- **排序与筛选**：按时间 / 名称 / 大小排序，即时筛选
- **统计条**：文件夹数、文件数、总大小
- **预览**：图片放大预览（可下载），文本类文件直接预览前 256 KB
- **管理**：打开（系统默认应用）、在资源管理器中显示、重命名、新建文件夹、删除（默认移入回收站，可恢复）
- **中英双语**：全部界面文案走 DSH locale 服务

## 安装

本插件随 profile 安装（**Plugins** > Add plugin 指向本目录，或 `plugin_manager install_bundle`），安装后重启 DSH 即生效。

## 配置（产物根目录）

三种方式，按优先级排列：

1. **面板设置（推荐）**：点面板右上角 **⚙**，用系统目录选择器选一个文件夹或手动输入完整路径，保存后立即生效。该配置通过 DSH 的 config editor 写进你自己的补丁层，升级插件不会丢。
2. **环境变量**：`DSH_ARTIFACTS_ROOT`。
3. **默认值**：`~/.dsh/artifacts`（首次启动自动创建）。

也可以直接在自己的补丁层（`cordis.patch.yml`）加一行按 id 覆盖：

```yaml
- id: dsh-artifacts
  config:
    root: 'D:\我的产物'
```

## 安全边界

- 所有文件请求被限制在配置的 `root` 之内，`..`、绝对路径、其他盘符一律 403
- 搜索不进入符号链接目录（不逃逸、不死循环），单次最多返回 200 条、最多扫描 20000 项
- 单层目录最多列出 2000 项；预览路由不服务超过 128 MB 的文件
- 删除默认移入产物根目录下的 `.dsh-artifacts-trash` 回收站（普通列表与搜索不可见）；恢复时按记录的原始位置放回，重名自动加 `(n)` 后缀，伪造的原始位置会被路径限制拒绝
- 回收站中的「彻底删除」与「清空回收站」为物理删除（文件夹递归），均有确认弹窗

## 结构

| 文件 | 说明 |
|---|---|
| `index.js` | Host 半：`.list` / `.file` / `.action` 三条经认证路由 |
| `client.js` | 浏览器半：`sidebar.panellist` 图标 + `main` 面板 |
| `locale/*.json` | 插件清单标题与描述（en / zh） |
| `icon.svg` | 插件图标 |
| `docs/DETAIL.md` | 插件详情页文档 |
| `test/*.mjs` | 独立冒烟测试：`npm test`（无需 cordis / 浏览器） |

## 测试

```sh
npm test   # node test/host.mjs && node test/search-fallback.mjs
```

- `test/host.mjs`：不依赖 cordis，伪造 connection / ctx 驱动全部 host 路由——列表 / 文件服务 / 动作 / 搜索 / 配置持久化，路径穿越与符号链接逃逸拒绝、Windows 保留名等断言
- `test/search-fallback.mjs`：伪造浏览器外壳加载真实 `client.js`，shim `fetch` 打真实路由，验证旧宿主（无 `.search` 路由）下的搜索回退、过期查询守卫与「隐藏代码」谓词

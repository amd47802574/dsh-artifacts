# 产物管家 (dsh-artifacts)

在 DeepSeek Harness 左侧栏新增一个「产物管家」入口，集中浏览和管理 DSH 生成的产物文件，卡片 / 列表两种视图一键切换，配色丰富。

## 功能

- **左侧栏入口**：侧栏底部新增彩色渐变图标的「产物管家」面板，点击进入中央面板。
- **产物目录可配置**：面板右上角 ⚙ 打开设置，用系统目录选择器或手动输入完整路径切换产物根目录，保存立即生效（经 config editor 写入用户补丁层）。未配置时默认使用 `~/.dsh/artifacts` 并在首次启动自动创建。
- **全局搜索**：顶栏输入产物名（支持中文），350ms 防抖后跨产物库全部子目录搜索；结果带所在文件夹路径，点击路径一键跳转，搜索结果同样支持预览、打开、重命名与删除。搜索不进入符号链接目录，单次最多返回 200 条。
- **目录浏览**：按目录层级浏览产物根目录（默认 `F:\desktop\草稿文件\dsh产物`），面包屑可跳转，支持上一级。
- **两种视图**：
  - **卡片视图**：按文件类型着色的渐变缩略卡（图片直接显示缩略图），悬停出现操作按钮。
  - **列表视图**：紧凑行布局，含类型、大小、时间列，悬停显示操作。
- **视图记忆**：卡片 / 列表的选择保存在本地，下次打开保持一致。
- **排序与筛选**：按时间 / 名称 / 大小排序（文件夹恒在前）。
- **统计条**：当前目录的文件夹数、文件数与总大小。
- **预览**：图片放大预览并支持下载；文本类文件（md / txt / json / 代码等）直接预览前 256 KB。
- **管理操作**：打开（系统默认应用）、在资源管理器中显示、重命名、新建文件夹、删除（删除有确认弹窗）。

## 配置

在 profile 的 `cordis.patch.yml` 中该插件的行内修改 `root` 字段即可更换产物根目录：

```yaml
- insert:
    - id: dsh-artifacts
      name: 'dsh-artifacts'
      config:
        root: 'F:\desktop\草稿文件\dsh产物'
```

## 配置

产物根目录按优先级：面板 ⚙ 设置（写入用户补丁层）> `DSH_ARTIFACTS_ROOT` 环境变量 > 默认 `~/.dsh/artifacts`（自动创建）。也可以在自己的补丁层按 id 覆盖：

```yaml
- id: dsh-artifacts
  config:
    root: 'D:\我的产物'
```

## 边界与限制

- 所有请求都被限制在配置的根目录之内，越权路径（`..`、绝对路径、其他盘符）一律拒绝；符号链接逐跳复核，链接目标在根外同样拒绝。
- 单层目录最多列出 2000 项，超出时页面顶部会提示截断；搜索最多返回 200 条、扫描 20000 项、深度 12 层。
- 预览路由不服务超过 128 MB 的文件；超大文本请用「打开」交给系统应用。
- 删除为立即生效的物理删除（文件夹递归），请谨慎操作；插件不提供回收站。
